OFICINA DO CELULAR - GESTAO V5

Esta versão mantém os dados locais da V4 e adiciona estrutura de PWA para acesso fácil no iPhone.

NO IPHONE:
1. Abra pelo Safari usando um link hospedado.
2. Toque em Compartilhar.
3. Escolha "Adicionar à Tela de Início".
4. Toque em Adicionar.
5. O sistema passa a aparecer como um aplicativo na tela inicial.

IMPORTANTE:
- O modo PWA/offline completo (service worker) funciona quando o sistema estiver hospedado em HTTPS. Abrir o HTML diretamente como arquivo é apenas para teste.
- Os dados desta fase continuam salvos no navegador do aparelho. A próxima etapa será colocar os dados em banco online para usar o mesmo estoque no iPhone, computador e tablet.
- Faça backups enquanto estiver usando a versão local.
